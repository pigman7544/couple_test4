# 우리 둘의 이야기 v6.5 — 사주 전용 테스트

- 본인/상대방의 생년월일, 성별, 출생시각 입력. 성별은 저장하지 않으며 사주 계산이나 인물 배역을 성별로 결정하지 않습니다.
- 사주만으로 관계 벡터 및 문학 커플 매칭. MBTI·별자리 사용 안 함.
- 무료 결과: 커플 이름, 이미지, 핵심 문장, 짧은 궁금증 유발 문구. 유료 본문은 서버 응답에 포함하지 않음.
- '5,000원 결제하고 전체 보기 (테스트 무료)' 버튼 클릭 시 /api/test-unlock으로 전체 리포트 조회. 실제 결제 없음.
- 백소정·허선(c06) 콘텐츠를 우선 개선했습니다. 다른 11쌍은 이전 시제품 원고를 유지합니다.

## Render 배포
ZIP 압축을 풀고 안의 모든 파일과 assets 폴더를 GitHub 저장소 루트에 업로드합니다. Render Blueprint는 render.yaml을 사용합니다.

## 주의
이 서비스는 전통 사주 상징을 활용한 문학적 관계 해석입니다. 생년월일만으로 실제 성격이나 미래를 검증해 예측하지 않습니다. 실제 결제 연동 전용 테스트 버전입니다.
